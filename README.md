# CodewithHafiz

GitHub Pages-ready frontend for the CodewithHafiz online learning website.

## Code Lab
The Code Lab has been redesigned with a VS Code-inspired dark developer workspace and green accent theme:
- Explorer/file tree with extension-based language badges
- Syntax-colored editor with line numbers, tabs, indentation, and editor scrolling
- Run button and terminal/output panel
- HTML/CSS/JavaScript browser preview
- Lightweight offline Python practice runner for common beginner code (`print`, variables, f-strings and simple `range()` loops)
- AI Assistant panel connected to the existing secure `/api/ai` flow
- New file, folder, and delete controls
- Local browser storage so Code Lab files remain on the same browser/device
- **Download Offline** button that creates a single self-contained offline Code Lab HTML file

### Important offline note
The downloaded single-file Code Lab does not require VS Code, an extension, or a Python installation. Browser-based HTML/CSS/JavaScript execution is supported. Python is handled by a lightweight practice runner; full CPython and third-party Python packages are not bundled into the website.

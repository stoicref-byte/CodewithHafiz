# CodewithHafiz

Professional white and emerald-green learning platform with separate frontend and backend.

## Run backend

1. Install Node.js LTS.
2. Open terminal inside `backend`.
3. Run:

```bash
npm install
npm start
```

Backend runs at `http://localhost:5000`.

## Run frontend

Open `frontend/index.html` with VS Code Live Server. It will call the backend at `http://localhost:5000`.
